# Textes légaux

La source unique des textes est `src/legal/documents.ts` (affichés dans l’app) et `src/legal/publisher.ts` (informations éditeur à compléter).

Pages publiques : `node scripts/build-legal-pages.js` régénère `docs/*.html`, publiées par GitHub Pages (Settings › Pages › branche `master`, dossier `/docs`).
